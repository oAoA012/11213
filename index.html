关于墨卡

墨卡（Mémorand）诞生于一个简单的念头：好的备忘录，应该像一张好纸——温润、克制、不打扰。

技术栈采用 React 18 + Vite + TailwindCSS + Zustand，后端基于 Node.js Express，部署于 Ubuntu 服务器，由 PM2 守护进程。所有数据按用户隔离存储，确保私密性。

设计语言取意"墨水卡"——赭石色为主调，纸白与墨夜双主题，配合细微的噪点纹理与浮动光晕，让数字记录也能有手作的温度。
